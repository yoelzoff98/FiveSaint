# Archivo de versiones anteriores

Estos archivos conservan la historia del trabajo y los procedimientos anteriores.
No forman parte de las migraciones automáticas y no deben ejecutarse como lote.

La actualización comercial vigente está en
`../migrations/20261003000100_commercial_release.sql`.
Los rollbacks antiguos no son una instrucción de despliegue. Para revertir la
aplicación, conservar el esquema y los documentos nuevos; evaluar por separado
la compatibilidad del código anterior. No eliminar columnas, tablas ni datos.
